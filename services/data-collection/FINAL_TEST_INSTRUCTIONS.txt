🎯 WHAT HAPPENS TECHNICALLY:

1. Notification: 
   Button URL → http://192.168.192.1:8004/redirect/6220e71d-3b03...

2. Redirect Page:
   Shows loading screen
   Auto-redirects to → exp://192.168.192.1:8081/--/sms-collect?requestId=...

3. Expo Deep Link:
   Expo Go intercepts the exp:// URL
   Opens your CUB app at /sms-collect route

4. App Auto-Starts:
   requestSMSPermission() → readTransactionSMS() → uploadSMSData()

5. Backend Receives:
   POST /api/sms/submit-data
   Parses SMS → Extracts transactions → Stores data

6. Dashboard Updates:
   Shows all parsed transactions and statistics

🐛 TROUBLESHOOTING:

"Still says cannot open URL":
  → Make sure Expo is running (npx expo start)
  → Check Expo port matches in redirect_handler.py
  → Try tapping "Open CUB App" button manually

"Browser opens but doesn't redirect":
  → Tap "Open CUB App" button manually
  → Make sure you're in Expo Go, not regular browser

"App opens but nothing happens":
  → Check if sms-collect route exists in your app
  → Look at app console logs in Expo

"Permission denied":
  → Settings → Apps → Expo Go → Permissions
  → Enable SMS permission
