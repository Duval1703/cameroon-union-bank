🐛 TROUBLESHOOTING:

Problem: Can't access http://192.168.192.1:8004 from phone

Solutions:
1. Verify both devices on SAME WiFi network
   
2. Check Windows Firewall:
   → Settings → Windows Security → Firewall
   → Advanced settings → Inbound Rules → New Rule
   → Port → TCP → 8004 → Allow the connection
   
3. Test backend from computer first:
   → http://localhost:8004 should work
   
4. Verify IP is still 192.168.192.1:
   → Run: ipconfig
   
5. Try disabling firewall temporarily for testing

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: SMS permission denied

Solutions:
1. Go to: Settings → Apps → CUB (or Expo Go)
2. Tap "Permissions"
3. Enable "SMS" manually
4. Restart the app and try again

Problem: No SMS messages found

Solutions:
1. Check if you have MTN/Orange Money SMS on phone
2. Messages should be in inbox (not archived/deleted)
3. App will use MOCK data in development if no real SMS found
   → This is normal for testing the flow
4. Mock data includes 8 sample transactions
