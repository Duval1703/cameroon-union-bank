  ⚡ 3-STEP SETUP (5 Minutes Total)
═══════════════════════════════════════════════════════════════════════

STEP 1: Create Your Telegram Bot (2 min)
──────────────────────────────────────────
  On your PHONE in Telegram:
  
  1. Search for: @BotFather
  2. Start chat and send: /newbot
  3. Name your bot: CUB Data Consent
  4. Username: cub_data_consent_bot (or any name ending in "bot")
  5. COPY the token BotFather sends you
     (looks like: 123456789:ABCdefGHIjklMNOpqrsTUVwxyz)


STEP 2: Configure Bot (2 min)
──────────────────────────────────────────
  On your COMPUTER:
  
  cd data_collection_agent
  python3 get_telegram_chat_id.py
  
  When prompted:
  - Paste your bot token
  - Press Enter
  
  On your PHONE:
  - Search for your bot (the username you created)
  - Open chat with your bot
  - Tap "START"
  - Send: /start
  
  On your COMPUTER:
  - Script shows: "✅ CHAT ID FOUND!"
  - Configuration saved automatically!


STEP 3: Restart Servers (1 min)
──────────────────────────────────────────
  cd data_collection_agent
  
  # Stop old servers
  pkill -f python
  
  # Start with Telegram enabled
  ./start_servers.sh
  
  You should see: "✅ Telegram notifications ENABLED"

═══════════════════════════════════════════════════════════════════════
  🔧 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

Problem: No notification received
───────────────────────────────────
  1. Check telegram_config.json has your bot token and chat ID
  2. Make sure "enabled": true in telegram_config.json
  3. Restart servers: ./start_servers.sh
  4. Check server log shows: "✅ Telegram notifications ENABLED"

Problem: "Invalid bot token"
───────────────────────────────────
  - Copy the FULL token from @BotFather
  - No spaces, no line breaks
  - Should look like: 123456789:ABCdefGHIjklMNOpqrsTUVwxyz

Problem: get_telegram_chat_id.py doesn't detect my /start
───────────────────────────────────
  1. Make sure you're chatting with YOUR bot (the one you created)
  2. Send /start command (not just tapping START button)
  3. Wait a few seconds
  4. Try running the script again
